## Flaticon Terms

_Scraped September 11th, 2026_

Attribution: How, when and where?

*If you are a Free user you must always attribute the author* when using our resources, below you can see the structure of the correct attribution line.

Let's see some examples:

In this link, you can see on the right side of the icon the name Pixel perfect: [Sushi](http://www.flaticon.com/free-icon/sushi_187463#term=sushi&page=1&position=68)

Therefore, the attribution line should be:

"Icon made by Pixel perfect from www.flaticon.com"

This one is made by Freepik, which is our own team: [Sushi](http://www.flaticon.com/free-icon/sushi_184452#term=sushi&page=1&position=66)

The attribution line would follow the same rules:

"Icon made by Freepik from www.flaticon.com"

You need to include one line for each author (not for each icon).
